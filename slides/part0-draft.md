# 격차는 지능이 아니라 활용에 있다

같은 모델, 다른 결과. 차이를 만드는 것은:

- **무엇을 주는가** — 컨텍스트 (난제에는 완결된 문제 정의가 있었다)
- **어떻게 맡기는가** — 위임 방식 (명확한 목표, 검증 가능한 형태)
- **어떻게 확인하는가** — 검증 (반례는 하루 만에 기계 검증됐다)
