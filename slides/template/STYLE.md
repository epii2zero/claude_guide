# 연구실 발표 템플릿 스타일 가이드

> 원본: `labmeeting-template.pptx` (DSP&AI Lab., Yonsei University 랩미팅 형식,
> 2026.08.07 발표본 기반, 32장). 앞으로 이 레포의 발표 슬라이드는 이 형식을 따른다.
> 최종 산출물은 이 템플릿에서 파생한 PPTX로 제작하고, Marp 초안은 문안 확정용으로 사용.

| 요소 | 크기 |
|------|------|
| 타이틀 슬라이드 제목 | 30pt, #003876, bold |

## 슬라이드 구조 관행 (덱 구성 순서)

1. **타이틀**: 제목(30pt, #003876) / 소속(DSP&AI Lab., Yonsei University) /
   발표자 / 날짜(YYYY.MM.DD)
2. **Overview**: 핵심 그림 1장 + 꺾쇠 캡션 + 주제 요약·Motivation 불릿
3. **Contents**: 섹션 목차 — **섹션이 바뀔 때마다 재등장** (현재 섹션 표시)
4. **섹션 표지**: 섹션명만 크게 (30pt, #003876), 여백 중심
5. **본문**: 상단 제목 + 그림/도표 중심 구성, 그림에는 꺾쇠 캡션,
   외부 자료 인용 시 상단에 10pt 출처 표기
6. 마지막: Conclusion 섹션

## 이 발표(Claude 가이드)에 적용할 때

- 파트 전환(인트로 → Part 1 → 휴식 → Part 2 → 마무리)에 **Contents 재등장 + 섹션 표지** 관행 사용
- 도식·캡처가 있는 장은 "그림 중심 + 꺾쇠 캡션" 구성으로
- 출처(공식 발표 링크 등)는 인용 관행에 따라 10pt로 상단/하단 표기
- Marp 초안(`part*-draft.md`)에서 문안을 확정한 뒤, 이 템플릿을 언팩·복제하여
  PPTX로 제작 (레이아웃: 제목 슬라이드 / 제목 및 내용 / 섹션 표지 활용)

## 참고 (분석 메모)

- 원본 32장, 레이아웃 10종 중 실사용은 "제목 슬라이드"(layout1),
  "제목 및 내용"(layout2)이 대부분

- 향후 새 랩미팅 템플릿이 나오면 이 파일과 가이드를 갱신할 것
